# Cat Escape: The Great Dog Chase

A mobile-first 3D endless runner built with **Three.js**, **JavaScript ES Modules**, **Vite**, **Web Audio API**, and **PWA** support.

## Features
- **3-Lane Endless Runner**: Smooth swipe & keyboard controls with 140ms input buffering and Near-Miss bonuses.
- **Dynamic Chase Director**: Skill-adaptive obstacle patterns and Boss Chase events (*Bulldog Rampage* & *Rush Hour*).
- **6 Progressive Worlds**: Vibrant City, Green Adventure Park, Neon Night City, Beach Adventure, Mysterious Forest, and Ancient Ruins.
- **Progression**: Unlockable Cat Skins, Daily Missions, Power-Ups (Magnet, Shield, Double Fish, Speed Boost), and `localStorage` persistence.
- **Android PWA**: Installable via Chrome (*Add to Home screen*) with offline service-worker caching.

## Run Locally
```bash
npm install
npm test
npm run dev
```
